# 2026-03-19 — Trading App Architecture Designed

## SYSTEM OVERVIEW
Designed a **3-agent trading automation platform** for retail traders.

### Agent 1: BOT EXECUTOR
- Automates trade execution from TradingView or manual entry
- Monitors 4+ pairs in parallel
- Risk management: configurable % per trade, daily loss limits
- Executes on Alpaca (paper/live), Blofin (crypto), Interactive Brokers
- Logs all trades + P&L

### Agent 2: ANALYST
- Reads daily research (Nikita's Markdown doc)
- Responds to trader queries (audio/text) with entry/tp/sl/probability
- Detects opportunities automatically (30-min scan)
- ML learning loop: improves recommendations based on historical win rates
- Uses OpenRouter LLM ($0.01 per analysis)

### Agent 3: LEADS
- Scrapes Twitter, LinkedIn, Reddit for trader prospects
- Scoring system (0-100 viability)
- Automated outreach (email/LinkedIn)
- Tracking: contacted → interested → trial → customer
- Commissions: 25% to referrer trader when someone converts

## INFRASTRUCTURE
- **VPS:** Hetzner $80/mo (shared across 50+ traders)
- **APIs:** Alpaca free, OpenRouter, SendGrid free tier, Elevenlabs TTS
- **Database:** PostgreSQL (main), Redis (cache), MongoDB (embeddings)

**HARDWARE:**

- User runs one-liner install script on server
- Auto-pairs + connects to Racha
- deployment_config.hardware_config contains: pairing_code, download_url, system_requirements

### Unified deployment_config JSON:
```
{
  deployment_type: 'cloud' | 'hardware',
  cloud_config: {...},        // If cloud
  hardware_config: {...},     // If hardware
  broker: {...},              // Same for both
  strategy: {...},            // Customizable
  monitoring: {...},          // Alerts, channels
  advanced: {...}             // Custom parameters
}
```

### Chat-driven workflow:
1. User: "Run this strategy 24/7"
2. Chat: "Cloud ($45) or Hardware (free)?"
3. User: "Cloud, US region"
4. System: Creates agent_config + deployment_config
5. OpenClaw: Deploys automatically
6. User: Gets notification "Agent live"

### Customization examples (all via chat):
- "Use 2x risk on this" → strategy.risk_percent = 3.0
- "Alert me on Telegram" → monitoring.notification_channels.push('telegram')
- "Use live Binance" → broker.account_type = 'live'
- "Only trade NY session" → advanced.timezone = 'America/New_York'

### Telegram integration:
- @racha_bot activate EUR strategy on hardware
- Bot responds with pairing code
- User installs on server
- Auto-pairs + confirms in Telegram

### New table structure:
- agent_configs.deployment_config = single JSONB field (not separate columns)
