## ⚠️ OVERLAPPING BATCHES - IMPORTANT RULES

Since Batches 5, 6, 7... will overlap with open orders:

```
RULE 1: Don't learn from incomplete orders YET
├─ Wait until they close (at profit target or stop)
├─ Don't use pending orders for analysis
└─ Only analyze COMPLETED fills

RULE 2: Track by batch ID + Timestamp
├─ Each order: batch_id, timestamp, entry_time, exit_time
├─ Allows deferred learning when orders complete
└─ Example: Batch 5 order completes during Batch 7 → log then

RULE 3: Overlapping risks managed
├─ Max simultaneous orders: 150 (across all batches)
├─ If total > 150: pause new batches
├─ Priority: Keep Batch 5-6 orders alive (don't cancel)

RULE 4: Learning priority order
├─ Completed orders (Batch 5) → Learn NOW
├─ Current batch (Batch 6) → Learn as they complete
├─ Recent batch (Batch 7) → Learn as complete
├─ Pending batch (Batch 8) → Plan for next improvement
```
