# PEACH&AGENTS - CONFIGURATION GUIDE

## 📋 WHO CONFIGURES WHAT?

This guide separates **DEVELOPER** responsibilities from **USER** responsibilities.

---

# 👨‍💻 DEVELOPER CONFIGURATION

**You** (as the platform creator) need to configure these things ONCE during setup.

## 1. GitHub Repository Setup

### What to do:
1. Create new GitHub repository
   - Name: `peach-agents`
   - Visibility: Public or Private
   - Initialize with README: No (you already have one)

2. Push code
   ```bash
   cd peach-agents-platform
   git remote add origin https://github.com/YOUR-USERNAME/peach-agents.git
   git branch -M main
   git push -u origin main
   ```

3. Repository settings (GitHub dashboard):
   - Settings → General
   - Default branch: `main`
   - PR template: Optional
   - Branch protection: Optional (recommended for production)

### Why:
- Source control
- CI/CD integration
- Team collaboration (if needed later)
- Deployment tracking

---

## 2. Vercel Deployment Setup

### What to do:
1. Connect GitHub to Vercel
   - Go to vercel.com
   - Click "New Project"
   - Select your `peach-agents` repo
   - Import

2. Configure Build Settings (auto-detected):
   - Framework: Next.js ✓
   - Build Command: `pnpm build` ✓
   - Output Directory: `.next` ✓

3. Add Environment Variables (see "Master Keys" below)

4. Deploy settings:
   - Auto-deploy on push: ✓ (enable)
   - Preview deployments: ✓ (enable)
   - Production: main branch

### Why:
- Continuous deployment
- Automatic preview URLs
- Production hosting
- SSL/TLS certificate (automatic)

---

## 3. Master Secrets (Only Developer Has These)

These are YOUR secrets as the platform owner. Keep them secure.

### JWT_SECRET
```
Generated by you (random 32+ character string)
Example: "super-secret-jwt-key-only-you-know-12345"
Keep in: .env.local (local), Vercel Secrets (production)
Never: Share, commit, expose
Used for: Signing authentication tokens
```

### PEACH_PASSWORD (Your Master Password)
```
Generated by you (strong password you remember)
Example: "MyUltraSecure@Password2026!"
Keep in: .env.local (local), Vercel Secrets (production)
NOTE: Users login with "peach" username + this password
Never: Tell users, share in code
Used for: Single-user authentication
```

### PEACH_EMAIL
```
Your email (or your organization email)
Example: "you@peach-agents.local" or "admin@company.com"
Keep in: .env.local, Vercel Secrets
Used for: Account identification
```

## 4. Third-Party API Keys Setup

These are YOUR credentials. You provide these to the platform.

### Alpaca (Paper Trading)
```
STEP 1: Go to https://app.alpaca.markets
STEP 2: Sign up (free - uses paper trading)
STEP 3: Settings → API Keys
STEP 4: Copy:
  - API Key
  - Secret Key
STEP 5: Add to Vercel as:
  - ALPACA_KEY
  - ALPACA_SECRET
  
IMPORTANT: 
- Paper trading = no real money risk
- Free = no charges
- Credentials = NEVER share with users
```

### Brave Search API (Google Alternative)
```
STEP 1: Go to https://www.search.brave.com/api/
STEP 2: Sign up
STEP 3: Create API key
STEP 4: Add to Vercel as:
  - BRAVE_SEARCH_API_KEY

NOTE: Free tier available
```

### YouTube API (Video Search/Transcripts)
```
STEP 1: Go to https://console.cloud.google.com/
STEP 2: Create new project
STEP 3: Search for "YouTube Data API v3"
STEP 4: Enable it
STEP 5: Create API key (Credentials)
STEP 6: Add to Vercel as:
  - YOUTUBE_API_KEY

NOTE: 
- Free tier: 10K units/day (more than enough)
- Generous limits
```

### Twitter API (Optional)
```
STEP 1: Go to https://developer.twitter.com/
STEP 2: Create app
STEP 3: Get Bearer Token
STEP 4: Add to Vercel as:
  - TWITTER_BEARER_TOKEN

NOTE: Optional - search works without it
```

## 5. Vercel Environment Variables

### What to set (in Vercel dashboard):

```
Environment Variables → Add

JWT_SECRET=your-secret-key-here
PEACH_EMAIL=you@peach-agents.local
PEACH_PASSWORD=YourSecurePassword123!
ALPACA_API=https://paper-api.alpaca.markets/v2
ALPACA_KEY=your-alpaca-key
ALPACA_SECRET=your-alpaca-secret
BRAVE_SEARCH_API_KEY=your-brave-key
YOUTUBE_API_KEY=your-youtube-key
TWITTER_BEARER_TOKEN=your-twitter-token (optional)
NEXT_PUBLIC_APP_URL=https://your-domain.vercel.app
```

### Important:
- Add ALL of these before deploying
- Use "Production" scope for production env
- Use "Preview" scope for preview URLs
- Redeploy after adding variables

## 6. Custom Domain Setup (Optional)

### If you want: https://your-custom-domain.com

```
STEP 1: Register domain
  - Example: peach-agents.com
  - Registrar: Namecheap, GoDaddy, etc.

STEP 2: In Vercel dashboard:
  - Project Settings → Domains
  - Add your domain
  - Follow DNS instructions

STEP 3: Configure DNS:
  - Add CNAME record pointing to Vercel
  - Wait 24-48h for propagation

STEP 4: Update in Vercel Secrets:
  - NEXT_PUBLIC_APP_URL = https://your-domain.com
  - Redeploy

STEP 5: SSL/TLS (automatic):
  - Vercel auto-enables
  - Free certificate via Let's Encrypt
```

# 👤 USER CONFIGURATION

**Your users** configure these things to use the platform.

## 1. Initial Login

### User does:
1. Go to your deployed URL: `https://your-domain.vercel.app`
2. Login with:
   - **Username**: `peach` (hardcoded - they can't change)
   - **Password**: Whatever you set as `PEACH_PASSWORD`

### User notes:
- Only one account (single-user mode)
- No registration page
- No password reset (ask developer if forgotten)

---

## 2. Create Trading Bots

### User does (in Management page):
1. Click "Create Bot"
2. Fill in:
   ```
   Bot Name: "My ForexMentor Bot"
   Strategy: "Trend Following" (dropdown)
   Symbols: Click to select (ETHE, GBTC, FXA)
   Allocation: Slider for each symbol
   ```
3. Configure entry/exit:
   ```
   Take Profit: 0.03 (3%)
   Stop Loss: -0.01 (-1%)
   Batch Size: 100 orders
   Wave Interval: 90 seconds
   ```
4. Click "Deploy"
5. Watch waves deploy in real-time

### User doesn't need to know:
- API keys (you provide)
- JWT tokens (automatic)
- Wave mechanics (handled behind scenes)

---

## 3. Search for Trading Strategies

### User does (in Research page):
1. Enter search query:
   ```
   "Best scalping strategies for EUR/USD"
   "ForexMentor recent trading signals"
   "Cryptocurrency bot strategies 2026"
   ```
2. Select sources:
   - YouTube ✓
   - Twitter ✓
   - Google ✓
   - Instagram (web only)
   - TikTok (web only)
3. Click "Search"
4. Results display with links

### User doesn't configure:
- API keys
- Rate limits
- Search algorithms
